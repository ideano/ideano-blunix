Content: - Place each column's content inside the shortcode. - Separate columns with the literal delimiter "<--->". - Each separated section is rendered as one
inside the responsive flex container. - Column content is output as safe HTML. Layout: - Uses a responsive flex layout. - On small screens, columns are stacked vertically. - From the md breakpoint upward, columns are displayed in a row. - Each column is flexible and has a minimum width of 100px. Example: {{< columns >}}

Column 1

<--->

Column 2

<--->

Column 3

{{< /columns >}} */}}

" | htmlUnescape | safeHTML }} {{ . | safeHTML }} {{ printf "
" | htmlUnescape | safeHTML }} {{ end }}
